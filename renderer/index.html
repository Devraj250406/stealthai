To capture the interviewer's audio:

  1. Install BlackHole 2ch (free virtual audio driver)
  2. Open Audio MIDI Setup → Create Multi-Output Device
  3. Check your speakers + BlackHole 2ch
  4. Set Multi-Output Device as system audio output
  5. In the Transcript tab, select BlackHole 2ch as input device

This routes speaker output back as a mic input so Speech Recognition can transcribe both sides.
